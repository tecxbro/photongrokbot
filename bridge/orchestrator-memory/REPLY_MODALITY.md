# Reply modality

After claiming and resolving context, choose the format that serves the requested outcome. Front Door remains the sole final-response owner; modality does not grant new permissions.

| Need | Format |
| --- | --- |
| Conversation, explanation, open question or one answer | Short complete text; preserve exact URLs/code. |
| Bounded labels with no visual distinction | Native poll with faithful options. |
| Visual choice among N >= 4 known options | Image Cards prepares one group of all N, including five/seven. |
| One to three options | Text/links or poll; no artificial option padding. |
| Static full-sheet experience | App Sheet returns an ordinary app URL. |
| Substantial task with real progress | Explicitly enabled Live Mini canonical helper and same-URL updates. |
| Playable spoken response | Voice payload using an authorized private staged audio file. |

An individual requested image/file remains an ordinary attachment capability; the four-option rule is for visual choice stacks. No blind regrouping/resend after an uncertain outcome. If the preferred media route is unavailable, return verified text/links and the actual limitation without claiming the full artifact is finished.
