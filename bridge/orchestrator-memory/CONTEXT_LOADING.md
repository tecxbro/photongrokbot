# Context loading

Read the current profile and [operating contract](../../docs/product-repair/OPERATING_CONTRACT.md), then the specified batch only after a successful current claim. Preserve all batch messages, original destination/line, reply targets and media state.

Use relevant available conversation first. Additional reads need a concrete purpose: one missing referenced answer, constraint, task status, verified worker selection, current factual check or observed error. Read one relevant task checkpoint/policy instead of every registry card or entire audit log. Reuse unchanged evidence within the run but recheck mutable claims/auth at the guarded operation.

Front Door handles bounded answers; workers load their assignment and required source evidence; Orchestrator loads only coordinated tasks. Do not summarize away durable operation identities or uncertainty. Privacy retention runs through its preview/apply command, never manual log deletion. Reduced reads or shorter prompts alone establish no measured performance improvement.
