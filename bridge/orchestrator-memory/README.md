# Compact operating references

The [operating contract](../../docs/product-repair/OPERATING_CONTRACT.md) governs all roles. This folder contains topic references, not a second mutable runtime database. `memory.md` points to the private verified registry; role cards are inert templates.

Core roles: Front Door, Master Orchestrator, Creator, Feature Add, Image Cards and App Sheet. Front Door answers directly or delegates and owns every final response. Creator repairs; Feature Add adds capabilities. Moonshine is mandatory at initial setup. The account shares one VM and one Spectrum runtime.

Use [context loading](CONTEXT_LOADING.md), [routing](CHAT_VS_TASK.md), [modality](REPLY_MODALITY.md), [attachments](ATTACHMENTS.md), [audio](AUDIO.md), [polls](POLLS.md), [apps](APPS.md), and [reactions/effects](REACTIONS_EFFECTS.md) when relevant. Do not write task/claim/onboarding/provider state to markdown.
