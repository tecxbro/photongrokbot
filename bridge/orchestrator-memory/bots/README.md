# Inert role templates

These cards summarize the [operating contract](../../../docs/product-repair/OPERATING_CONTRACT.md); they do not configure active workers. `bun run setup-state -- registry` from bridge/ reads the private verified core registry. Only explicitly configured verified workers may receive assignments.

Render actual identities into private deployed profiles after authorized setup. Keep tracked placeholders unchanged. Never populate this folder with another account's personal roster, conversation history or credentials. Front Door remains the sole final-response owner. The role summaries are generated by `bridge/scripts/generate-role-instructions.ts` and checked against their source catalog.
