## Cleanup, limits, and unverified gates

Temporary `.partial` files are deleted in finally; derived WAV is deleted after worker STT; original audio and HEIF originals remain durable record references. Worker-owned inbound directory namespace is `media-job-<24hex>-<uuid>`. Crashes can leave these owned directories with `.partial`, `.partial.wav`, `.partial.jpg` or unreferenced original files; retention must subtract all DB references and avoid active pending/processing jobs, then apply the product's 7-day unused-artifact policy. Outbound `converted` contains content-hash final JPEGs and UUID partial files. Never apply cleanup to guessed legacy paths.

FFmpeg gets single-thread, allocation, output-byte, allowed-format and network-protocol restrictions. Python adds CPU/file/core/Linux address-space limits. Full OS filesystem sandbox and an operator-provisioned Linux cgroup are not established from this local source work; decoder memory/CPU performance and cgroup support are actual environment gates. Buffer-only providers can allocate before their result is checked; stream mode avoids that path for the locked Spectrum SDK. Real Moonshine model hash verification, inference accuracy/latency, actual shared-VM runtime, network cancellation/provider persistence, iPhone voice/HEIF behavior and live wiring were not exercised. None is claimed as passed.
